# Rajat Sharma — Data Scientist & AI/ML Engineer Portfolio

An interactive, editorial brutalist portfolio showcasing production AI/ML architectures, retrieval-augmented generation (RAG) systems, vehicular cybersecurity telemetry, and deep learning engineering.

## 🚀 Highlights & Features
- **Cinematic Experience**: Custom procedural Web Audio with Tone.js, 3D perspective transforms with GSAP ScrollTrigger, and silky-smooth Lenis scrolling.
- **Physical Notebook & Blueprint**: Interactive draggable stickers, mathematical loss & attention watermarks, live dynamic telemetry stamps.
- **Interactive Jaipur Metro Transit**: Subway car exploration with Pink Line (JMRC) stations and interactive case study displays.
- **Production AI Systems**:
  - **AutoSifu**: Real-time CAN-bus anomaly detection & vehicular cybersecurity.
  - **PDF RAG Assistant**: Multi-document semantic retrieval & context re-ranking with LangChain & ChromaDB.
  - **Neural Audio Synthesizer**: Generative deep learning audio composition pipeline with PyTorch.
  - **Agentic AI Workflow**: Multi-agent tool execution and vector memory architecture.

## 🛠️ Tech Stack
- **Languages & Frameworks**: Python, JavaScript (ES6+), HTML5, Vanilla CSS
- **AI / ML / Data Science**: PyTorch, TensorFlow, Scikit-Learn, LangChain, Hugging Face, Pandas, NumPy, ChromaDB
- **Animations & Audio**: GSAP, Lenis, Tone.js
- **Tooling**: Docker, FastAPI, Git, GitHub
